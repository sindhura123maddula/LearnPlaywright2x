# JavaScript Shortcuts in VS Code (Windows)

## Editing Shortcuts

| Shortcut | Description |
|----------|-------------|
| `Ctrl + X` | Cut line (empty selection) |
| `Ctrl + C` | Copy line (empty selection) |
| `Ctrl + Shift + K` | Delete line |
| `Ctrl + Enter` | Insert line below |
| `Ctrl + Shift + Enter` | Insert line above |
| `Alt + Down` | Move line down |
| `Alt + Up` | Move line up |
| `Shift + Alt + Down` | Copy line down |
| `Shift + Alt + Up` | Copy line up |
| `Ctrl + D` | Add selection to next find match |
| `Ctrl + K Ctrl + D` | Move last selection to next find match |
| `Ctrl + U` | Undo last cursor operation |
| `Shift + Alt + I` | Insert cursor at end of each line selected |
| `Ctrl + Shift + L` | Select all occurrences of current selection |
| `Ctrl + F2` | Select all occurrences of current word |
| `Ctrl + I` | Select current line |

## Commenting Shortcuts

| Shortcut | Description |

## Code Navigation Shortcuts

| `F8` | Go to next error or warning |
| `Shift + F8` | Go to previous error or warning |
| `Ctrl + Shift + .` | Go to bracket |
| `Ctrl + K Ctrl + X` | Trim trailing whitespace |

## Terminal Shortcuts

|----------|-------------|
| `` Ctrl + ` `` | Toggle integrated terminal |

| `Ctrl + Shift + C` | Copy selection in terminal |

## Search & Replace Shortcuts

| Shortcut | Description |
|----------|-------------|
| `Ctrl + F` | Find |
| `Ctrl + H` | Replace |
| `F3` | Find next |
| `Shift + F3` | Find previous |
| `Alt + Enter` | Select all occurrences of Find match |
| `Ctrl + D` | Add selection to next Find match |
| `Ctrl + K Ctrl + D` | Move last selection to next Find match |
| `Ctrl + Shift + F` | Search in files |
| `Ctrl + Shift + H` | Replace in files |

> **Tip:** You can customize these shortcuts in VS Code by going to **File > Preferences > Keyboard Shortcuts** (`Ctrl + K Ctrl + S`).
